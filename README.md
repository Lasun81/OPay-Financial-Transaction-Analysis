## Project Overview

The **OPay Financial Transaction Analysis Dashboard** is an end-to-end data analytics project developed to analyse real-world digital wallet transaction records covering seven months (April–October 2026).

The project focuses on transforming raw financial transaction data into meaningful insights through data cleaning, transformation, analysis and interactive visualization.

The entire workflow involved using **Microsoft Power Query** for data cleaning and preparation, **Figma** for dashboard UI/UX design, and **Microsoft Power BI** for data modelling, analysis and dashboard development.

The final dashboard provides an overview of financial activities, including total credits, total debits, transaction volume, transaction channels, significant incoming and outgoing transactions, and wallet balance movements.

## Project Objectives

The major objectives of this project were to:

- Clean and transform raw OPay transaction records into an analysis-ready dataset.
- Identify and address data quality issues using Power Query.
- Examine financial inflows and outflows over the analysis period.
- Understand monthly income and expenditure patterns.
- Analyse transaction distribution across different channels.
- Identify the highest credit and debit transactions.
- Monitor changes in wallet balance over time.
- Develop an interactive and visually appealing financial analytics dashboard.

## Project Workflow

### 1. Data Collection and Understanding

The project started with real OPay wallet transaction records covering April to October 2026.

The initial dataset was examined to understand its structure, transaction categories, available fields and suitability for financial analysis.

The goal was to understand the movement of money into and out of the wallet and identify the key metrics required for the analysis.

### 2. Data Cleaning and Transformation Using Power Query

Power Query was used to clean and transform the raw transaction records before loading the prepared data into Power BI.

The cleaning process involved:

- Inspecting the dataset for inconsistencies.
- Checking and correcting data types.
- Identifying missing and inconsistent values.
- Removing irrelevant fields and unwanted records where necessary.
- Standardizing transaction information.
- Preparing date fields for time-based analysis.
- Ensuring the dataset was properly structured for visualization.

This stage was important in improving data quality and ensuring the reliability of the subsequent analysis.

### 3. Dashboard UI/UX Design Using Figma

Before developing the dashboard in Power BI, I created a Figma-inspired dashboard interface to establish the visual direction and layout of the project.

The design adopted a modern fintech appearance, incorporating:

- Mint green, white and navy blue colour combinations.
- A structured sidebar navigation layout.
- Modern KPI cards.
- Dedicated spaces for charts and visualizations.
- Clean typography and consistent spacing.
- A professional and user-friendly interface.

The design was created to make financial information easy to understand while maintaining a clean and organized reporting experience.

### 4. Data Modelling and Analysis in Power BI

After completing the cleaning and transformation process, the prepared dataset was loaded into Microsoft Power BI.

The data was then used to develop the necessary analytical measures and visualizations.

The analysis focused on financial inflows, outflows, transaction volume, transaction channels, significant transactions and wallet balance movements.

### 5. Dashboard Development in Power BI

The final dashboard was developed in Power BI using the Figma-inspired interface as the visual background.

The dashboard consists of **3 Key Performance Indicators (KPIs) and 5 major visualizations.**

#### Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Total Credits | Measures the total amount of money received into the wallet. |
| Total Debits | Measures the total amount of money spent or transferred out of the wallet. |
| Total Transactions | Shows the overall number of recorded transactions. |

#### Dashboard Visualizations

| Visualization | Description |
|---|---|
| Monthly Income & Expenses | Compares monthly financial inflows and outflows. |
| Transaction Channels | Examines the distribution of transactions across mobile and web channels. |
| Highest Credit Transactions | Identifies the largest incoming transactions. |
| Highest Debit Transactions | Highlights the largest outgoing transactions. |
| Balance Trend | Tracks changes in wallet balance throughout the analysis period. |
